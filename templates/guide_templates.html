Templates in the folder

Create templates inside the campaign folder so Manage can pick Template A (and B for A/B). The first template in the folder is usually Template A after sync.

Merge tags & Jev

  1. Personalize with {{"{{variable}}"}} — optional filters like {{"{{first_name|title}}"}} when documented in the editor.
  2. Use mailbox tags (e.g. sender name) when seats rotate.
  3. Run Jev for a structured review (placeholders, tone, deliverability risk). Treat it as a checklist, not gospel.
  4. Preview against real contacts before launch.

Copy that earns replies

  • One idea, one ask. Short subject that sounds human.
  • ~50–125 words for cold; write a different follow-up — don’t paste the intro again.
  • Tracked links only when they help; they feed engagement signals when tracking is on.

Common mistakes

  • Variables that don’t exist on the contacts sheet.
  • Walls of text or three CTAs.
  • Shipping AI drafts without a human pass.
