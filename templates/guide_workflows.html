Sequences live on Manage

Multi-touch outreach is configured on the campaign Manage page — not as a separate “attach published workflow” flow. Set campaign type to Sequence (or Sequence + A/B), then open Edit sequence.

Building a sequence

  • First email uses Template A (and B if A/B is on).
  • Add follow-ups with wait days and a template from the folder.
  • Optional recommended preset fills a simple 3-touch from folder templates — edit before launch.
  • With local-time sending enabled, follow-up wakes snap to the preferred local clock after the wait.

Reply watchers & stop rules

  • Stop on reply / stop on hot cancel remaining sequence steps.
  • Reply watchers map inbound intents (interested, meeting, pricing, OOO, …) to a reply template. After a short delay, Jev verifies the reply fits, then auto-sends — or skips with a note.
  • unsubscribe / wrong_person never auto-reply.

Legacy workflows

Old graph-based workflow campaigns are retired for new outreach. If Manage shows a legacy banner, switch the type to Sequence and rebuild steps there. Library “workflow” files are optional extras — sequences on Manage are the source of truth.
