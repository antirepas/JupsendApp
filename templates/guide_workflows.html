Where things live now

Sequences vs reply watchers

Outreach sequences (email → wait → follow-up) are configured on the campaign Manage page — Edit sequence modal. Reply watchers map inbound intents (interested, meeting ask, pricing, OOO, …) to a template that auto-sends after a short delay if Jev verifies the reply.

Outreach playbook Campaigns guide

Manage sequence

  • Set campaign type to Sequence or Sequence + A/B first email.
  • Open Edit sequence — first email uses Template A/B; add follow-ups with wait days.
  • Optional: Apply recommended for a simple 3-touch preset from folder templates.

Reply watchers

  • On Manage, map each intent to a reply template (or leave blank).
  • When a reply arrives, Jev classifies intent, waits ~1–2 minutes, verifies the template answers the inbound message, then auto-sends — or skips with a system note.
  • unsubscribe / wrong_person never auto-reply (suppress / stop path).

Legacy workflows

Old send→wait→send workflow graphs are no longer used for outreach. Campaigns still on legacy workflow mode show a banner — switch to Sequence and reconfigure steps before launch.
