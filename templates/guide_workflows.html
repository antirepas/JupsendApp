What workflows do

Workflows run multi-step sequences for each contact: send an email, wait, branch on whether they opened or clicked, send a follow-up, and stop. Use them when a single campaign isn't enough — e.g. reminder if no open after 3 days.

Building a workflow

  1. Create templates for each step first (same as campaigns).
  2. Go to Workflows → New and open the visual builder.
  3. Drag nodes: Send email, Wait, Condition (opened? clicked?), End.
  4. Connect nodes with edges; set template and delay on each action node.
  5. Enroll contacts via the workflow (or tie to campaigns where supported).

When to use workflows vs campaigns

  • Campaign — one blast to a list, track aggregate results
  • Workflow — timed follow-ups and conditional branches per contact
