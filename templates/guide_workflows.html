Recommended system

Don’t start from a blank canvas

Use the jupsend outreach playbook — A/B cold → temperature → value prop or breakup → manual Loom close. Full copy skeletons and campaign checklist included.

Read outreach playbook

Node types

  • Start — campaign launched for a contact.
  • Send email — maps to a template on the campaign.
  • Wait — pause days before the next check or send.
  • Condition — yes/no on opened, clicked, replied (optionally after a wait).
  • Lead temperature — three-way branch: hot / warm / cold using this campaign’s temperature rules.
  • End — sequence complete for that contact (use one path for “manual Loom”).

Build → publish → attach

  1. Clone the playbook or build in the canvas; connect yes/no or hot/warm/cold edges.
  2. Publish a version (drafts aren’t launchable).
  3. Create a workflow (or workflow A/B) campaign and select that published version.
  4. Map a template to every send step on the campaign page.
  5. Add contacts and launch — each contact gets a workflow instance.

Replies stop the sequence

When a contact replies, remaining automated steps cancel for them. Treat that as success: move to Interested and continue the conversation yourself.

Common mistakes

  • Lead temperature node without hot, warm, and cold edges (won’t publish).
  • Condition on “not opened” with no wait — everyone fails instantly.
  • Editing a live published graph without understanding draft-fork: publish creates the version campaigns use.
