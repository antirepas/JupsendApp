Why import contacts?

Contacts are the people you email. Each contact has an email address plus optional variables (like name or company) that fill {{"{{placeholders}}"}} in your templates. Import a list once, then reuse it across campaigns.

Step-by-step

  1. 1Open Contacts → Import.
  2. 2Paste rows from a spreadsheet (one contact per line: email or email,name,company), or upload an Excel file (.xlsx).
  3. 3Optionally pick a template so column names match your variables, or let jupsend detect columns from the header row.
  4. 4Optionally add everyone to a list so you can target them together in campaigns. List members should share the same variable names.
  5. 5Confirm the import. You can also add one contact at a time with New contact.

Tips

  • Always include an email column — other columns become template variables.
  • Use the same variable names in templates and imports (e.g. company name).
  • Download a sample Excel file from the Import tab if you want a ready-made format.
  • Invalid or bounced addresses can be managed under Suppressions.
