Why import contacts?

Contacts are the people you email. Each contact has an email address plus optional variables (like name or company) that fill {{"{{placeholders}}"}} in your templates. Import a list once, then reuse it across campaigns.

Step-by-step

  1. 1Open Contacts → Import.
  2. 2Paste rows or upload Excel/CSV. Column names do not need to be exact — you’ll map them.
  3. 3In the mapping dialog, pick which column is email, skip unused columns, and keep the rest as variables (name, company, …).
  4. 4Optionally add everyone to a list so you can target them together in campaigns.
  5. 5Confirm the import. You can also add one contact at a time with New contact.

Tips

  • Headers like Email Address work — map them to Email in the dialog.
  • Skip columns you don’t need; map others to variable names that match your templates.
  • If a cell has several emails separated by , or ;, we keep one preferred address per row (hello@ → contact@ → support@ → first valid).
  • Download a sample Excel file from the Import tab if you want a ready-made format.
  • Invalid or bounced addresses can be managed under Suppressions.
