Recommended outreach workflow

One click loads this sequence as a draft. Publish it, attach a workflow A/B campaign, map templates, and launch.

The idea

jupsend isn’t just a mailer — it’s a system for running outbound the correct way. Automate qualification; close the best leads yourself.

  • A/B a cold intro so you learn which opener works.
  • Temperature splits hot / warm / cold from opens, clicks, and replies (campaign rules).
  • Warm + hot get a value prop. Still engaged → you send a personalized Loom + Calendly.
  • Cold get a no-engagement nudge, then a polite breakup — then stop.

How the sequence flows

  1. 1
    Cold intro (A/B) — short, one ask. Campaign mode: workflow A/B maps template A and B to this first send.
  2. 2
    Wait 3 days — give humans time; don’t branch on “not opened” in hours.
  3. 3
    Temperature #1 — hot/warm → value prop; cold → no-engagement nudge.
  4. 4
    Value prop (engaged path) — proof, outcome, or insight. Wait 3 days → temperature again.
  5. 5
    Temperature #2 — still hot/warm → End — send Loom + Calendly (manual). Cooled off → join the nudge path.
  6. 6
    No-engagement → wait → breakup → end — clear, respectful exit. Don’t keep pinging forever.

What you automate vs what you do yourself

  • Automated: cold A/B, waits, temperature branches, value prop, nudge, breakup.
  • Manual (on purpose): when a contact stays hot/warm through the sequence, record a short Loom tailored to them and include your Calendly link. That’s the close — not another template blast.
  • Replies: stop-on-reply should stay on. A reply is success — continue in Interested, not in the sequence.

Copy skeletons (paste into Templates)

Keep each email to one idea and one ask. Swap in your ICP language.

1. Cold intro (variants A & B)

Subject A: quick question about {{"{{company}}"}}
Subject B: {{"{{first_name}}"}} — worth a look?

{{"{{first_name}}"}}, noticed {{"{{company}}"}} is [specific observation].
We help teams like yours [one outcome in plain language].
Worth a 2-sentence reply if this is on your plate?

2. Value prop (warm / hot)

Subject: why teams like {{"{{company}}"}} use this

Quick follow-up with the concrete piece:
• [proof / metric / customer story]
• [how it maps to their situation]
If useful, happy to show a 2‑min walkthrough — otherwise ignore.

3. No-engagement nudge (cold)

Subject: still relevant?

Totally fine if timing is off. Should I close the loop, or is [problem] still something you’re solving this quarter?

4. Breakup

Subject: closing the loop

I’ll assume this isn’t a priority and stop emailing.
If that changes, reply anytime — happy to pick it back up.

Campaign setup checklist

  1. Clone the workflow → review graph → Publish.
  2. Create a workflow A/B campaign; select the published version.
  3. Map templates to send steps 1–4 (A/B only on the cold intro).
  4. Set lead temperature (defaults work: warm ≈ 2 opens + 1 click; hot ≈ 3 opens + 2 clicks; reply = hot).
  5. Keep stop on reply on. Optional: stop on hot if you want zero automation after strong interest.
  6. Launch, then work Interested daily for replies and Loom-ready hot/warm leads.

Failure modes

  • Everything stays cold — rewrite the A/B intro (subject + first line) before adding more touches.
  • Opens but no replies — soften the ask; check deliverability and bot opens on Sends.
  • Reply rate spikes — pause volume, answer everyone, then scale the winning variant.
  • Skipping the Loom — automation warmed them; a generic fifth email wastes the win.
