Why this order

Perfect outreach is a system: a trustworthy sender, a clean list, a clear message, a smart sequence, then disciplined follow-up on interest. Skip steps and you burn domain reputation or send generic mail nobody answers.

1. Get a mailbox ready

Free: jupsend attaches a shared sending address — confirm Mailboxes shows send-ready.

Pro: buy or connect your outreach domain, wait until seats are ready, then send a test.

Open Mailboxes · Mailboxes playbook

2. Import contacts the right way

  1. Use a dedicated outreach list (not your whole CRM dump).
  2. Map columns so {{"{{first_name}}"}} (and similar) actually fill.
  3. Prefer one best email per row; suppress bad addresses.

Import contacts · Contacts playbook

3. Write a reply-worthy template

  • One idea, one ask. Subject that sounds human.
  • Personalize with real variables — never “Hi {{"{{first_name}}"}}” empty.
  • Include a tracked link only when it helps the story.

Create template · Templates playbook

4. Use the recommended workflow

Clone the default outreach sequence: A/B cold intro → wait → temperature → value prop (warm/hot) or no-engagement → breakup (cold). Hot/warm at the end stop so you can send a personalized Loom + Calendly. Publish before attaching to a campaign.

Outreach playbook →

5. Launch a campaign

  1. Pick bulk (one send) or workflow / workflow A/B.
  2. Set lead temperature rules (e.g. warm = 2 opens + 1 click).
  3. Add contacts, map templates to send steps, then send or schedule.

Create campaign · Campaigns playbook

6. Work interested leads daily

Replies and engaged contacts appear under Interested. Follow up personally while they’re warm — don’t wait for the next automated bump if they already replied.

Interested contacts · Interested playbook · Analytics

Common mistakes

  • Sending from a brand-new domain with no warmup / huge volume day one.
  • Launching a workflow campaign without mapping every send step’s template.
  • Trusting raw opens without checking bot/scanned opens on send detail.
