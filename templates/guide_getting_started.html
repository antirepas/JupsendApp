How jupsend is organized

Each outreach effort lives in a campaign folder (Library): templates, a contacts sheet, and Manage in one place. You don’t wire a separate “workflow campaign” anymore — sequences are configured on Manage.

1. Subscribe, then explore

After checkout you can use the whole product. Domains and mailboxes are add-ons — set them up when you’re ready to send, not as a gate on day one.

Billing · Mailboxes · Mailboxes guide

2. Create a campaign folder

  1. Open Library / Campaigns and create a folder — jupsend creates the draft campaign for it.
  2. Add at least one email template in that folder.
  3. Add a contacts sheet (or import into it) with the columns your copy needs.

Campaigns · Campaigns guide

3. Write templates that merge cleanly

  • Use {{"{{first_name}}"}}-style variables that exist on the sheet.
  • Run Jev in the editor for a quick quality pass — then edit for truth.
  • Sign with mailbox-aware tags when you rotate seats.

Templates guide

4. Configure the campaign on Manage

  1. Choose type: one-time, one-time A/B, sequence, or sequence + A/B first email.
  2. For sequences, open Edit sequence — waits and follow-up templates live there.
  3. Optional: lead temperature, stop-on-reply, reply watchers, open tracking.
  4. Schedule: one absolute time, or each contact’s local time via a location column + date + clock time.

Sequences guide

5. Launch, then work replies

Send or schedule from Manage. Watch queue progress, then live in Inbox → Interested for positive replies. Automation can stop remaining steps; you still close the deal yourself.

Interested · Interested guide

Common mistakes

  • Huge volume on a brand-new domain with one cold seat.
  • Launching a sequence with empty follow-up templates.
  • Local-time schedule without a usable country/timezone column.
  • Ignoring Interested while positive replies pile up.
